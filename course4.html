Online Webinar 4:
Software Testing

NARRATIVE REPORT

On August 29, 2026, I attended a two-hour online webinar called “QA 101: Software Testing | The Tech Job Nobody Talks About”. The webinar was conducted by UpSkillTechPH Training Services.

During the webinar, I learned more about software testing and why it is important when creating applications and systems. I learned that testing helps find problems or bugs and makes sure that software works properly before it is used by people. We also discussed test planning, creating test cases, finding bugs, reporting issues, and test automation.

One part that I found interesting was learning about the different types of software testing, such as functional testing, UI testing, regression testing, performance testing, and User Acceptance Testing (UAT). I also learned what a test plan contains, including the project information, scope, features to test, resources, schedule, and possible risks.

Overall, I found the webinar helpful because it gave me a better idea of what software testers and QA professionals actually do. As a student, I learned that testing is not just about finding mistakes but also about making sure that an application is reliable and easy to use. The knowledge I gained from the webinar can help me with my programming studies and future projects.
